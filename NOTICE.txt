## 📡 APIs (Interfaces de Programação de Aplicações)

### 1. Open-Meteo Geocoding API

**Provedor:** Open-Meteo  
**Website:** https://open-meteo.com/  
**Documentação:** https://open-meteo.com/en/docs/geocoding-api

**Uso:**  
Utilizada para converter nomes de cidades em coordenadas geográficas (latitude e longitude).

**Licença:** CC BY 4.0 (Creative Commons Atribuição 4.0 Internacional)  
**URL da Licença:** https://creativecommons.org/licenses/by/4.0/deed.pt_BR

**Atribuição:**
```
Dados meteorológicos fornecidos por Open-Meteo.com
```

**Endpoint da API:**
```
https://geocoding-api.open-meteo.com/v1/search
```

**Termos de Uso:**
- Gratuito para uso não comercial e comercial
- Atribuição obrigatória
- Não requer chave de API

---

### 2. Open-Meteo Weather Forecast API

**Provedor:** Open-Meteo  
**Website:** https://open-meteo.com/  
**Documentação:** https://open-meteo.com/en/docs

**Uso:**  
Utilizada para recuperar dados meteorológicos em tempo real, incluindo temperatura, velocidade do vento, direção do vento e condições climáticas.

**Licença:** CC BY 4.0 (Creative Commons Atribuição 4.0 Internacional)  
**URL da Licença:** https://creativecommons.org/licenses/by/4.0/deed.pt_BR

**Atribuição:**
```
Dados meteorológicos fornecidos por Open-Meteo.com sob licença CC BY 4.0
```

**Endpoint da API:**
```
https://api.open-meteo.com/v1/forecast
```

**Fontes de Dados:**
- NOAA (Administração Nacional Oceânica e Atmosférica dos EUA)
- DWD (Serviço Meteorológico Alemão)
- ECMWF (Centro Europeu de Previsões Meteorológicas de Médio Prazo)

## 🔒 Segurança e Privacidade

### Sem Coleta de Dados do Usuário
Esta aplicação **não coleta, armazena ou transmite quaisquer dados pessoais do usuário**. Todas as requisições de API são feitas diretamente do cliente para serviços de terceiros.

**As buscas são processadas em tempo real** sem armazenamento de histórico ou informações pessoais.

### Políticas de Privacidade das APIs
- Open-Meteo: https://open-meteo.com/en/terms
- Google Fonts: https://developers.google.com/fonts/faq/privacy

## ⚖️ Conformidade Legal

### Conformidade com LGPD (Brasil)
Esta aplicação está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018) brasileira.

**Princípios seguidos:**
- Não coleta de dados pessoais
- Transparência total sobre uso de dados
- Processamento em tempo real sem armazenamento

Esta aplicação está em conformidade com o Regulamento Geral de Proteção de Dados (GDPR) europeu.
